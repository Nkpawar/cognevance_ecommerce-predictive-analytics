# E-Commerce Customer Intelligence & Predictive Analytics System

## 📌 Project Overview

The E-Commerce Customer Intelligence & Predictive Analytics System is an end-to-end data analytics and machine learning project developed to analyze customer behavior, sales performance, product performance, and customer value.

The project uses transaction data from the UCI Online Retail II dataset and combines Python, SQL, Machine Learning, and Power BI to transform raw transaction data into actionable business insights.

---

## 🎯 Project Objectives

- Analyze e-commerce transaction data.
- Clean and preprocess large-scale transactional data.
- Calculate customer Recency, Frequency, and Monetary (RFM) metrics.
- Segment customers based on purchasing behavior.
- Analyze product and country-level sales performance.
- Identify high-value customers using Machine Learning.
- Perform advanced SQL analysis using CTEs and window functions.
- Build an interactive Power BI analytics dashboard.
- Generate business insights for customer retention and revenue growth.

## 📊 Dataset

The project uses the **UCI Online Retail II Dataset**.

Dataset source:

https://archive.ics.uci.edu/dataset/502/online+retail

The dataset contains online retail transaction records including:

- Invoice
- Stock Code
- Description
- Quantity
- Invoice Date
- Price
- Customer ID
- Country

The raw dataset is intentionally excluded from GitHub through `.gitignore`.
